# Security Policy

## Supported Versions

Security fixes are handled on `main` until the project publishes stable release
branches.

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub's security advisory flow
for this repository. If advisories are unavailable, email the maintainer at
security@logicpromcp.dev with a minimal reproduction and avoid opening a public
issue until the report is triaged. Encrypted reports via PGP are preferred; see
repository wiki for public key. Expect an initial response within 72 hours.

For issues involving local macOS permissions, include:

- macOS version
- Logic Pro version
- LogicProMCP version or commit SHA
- Whether Accessibility, Automation, MIDI, or OSC permissions are involved

Do not include Logic project files, credentials, private keys, or other secrets
in reports.
