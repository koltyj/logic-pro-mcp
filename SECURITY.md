# Security Policy

## Supported Versions

Security fixes are handled on `main` until the project publishes stable release branches.

## Reporting a Vulnerability

Please report vulnerabilities privately through this repository's GitHub security advisory flow. Do not open a public issue for an unpatched vulnerability.

For issues involving local macOS permissions, include the macOS, Logic Pro, and LogicProMCP versions and identify whether Accessibility, Automation, MIDI, or OSC permissions are involved.

Do not include Logic project files, credentials, private keys, or other secrets.
